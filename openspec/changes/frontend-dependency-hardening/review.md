## Safety-regression design

The new standalone browser harness feeds a registered disposable Markdown file to the actual production FileViewer. It asserts ordinary formatting/code survive while script/iframe tags, event attributes and javascript URLs do not; harmless marker assignments must not execute. Raw registered-file bytes remain unchanged. External network requests, real user projects and model calls are excluded. This is regression coverage, not a proof against all XSS classes.
